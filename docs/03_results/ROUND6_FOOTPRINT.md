## Reading

1. The forest is 15,771 bytes of constant data in flash (about 15.4 KiB); the HMAC path and the micro-confirm code are a few hundred bytes of code.
2. The largest stack frame is `cg_hmac_sha256` (it builds the padded inner and outer messages on the stack); the chain of the micro-confirm check needs 1568 bytes by this static sum.
3. The linker of this toolchain stopped with a segmentation fault under `--gc-sections` in WSL, so the linked image keeps unused functions; the per-function rows give the size of the used path.
