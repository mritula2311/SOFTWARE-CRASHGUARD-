## 0. Common rules

- **Data (NHTSA studies P1 to P3).** The 913 pooled records of Z0 (174 + 739). Folds: development (543 records), validation (184), SEALED test (186), whole make-and-model groups together (group = make + leading word of the model). Reference delta-V = the N13 reference (maximum of the running integral over 300 ms of the unclipped, original-rate signal). Modes: frontal barrier, pole, side, other (definitions in `docs/05_data_code/SEALED_SPLIT.md`).
- **Severity classes.** Low, Moderate, Severe, Critical from the resultant delta-V with the limits 24, 40 and 56 km/h (`config.SEV_DV_KMH`), the classes of the UA-SCT study. **Stated deviation:** the UA-SCT classes also take the maximum with an ASI class; the reference ASI exists only for the original 176 tests (not for the 739 T13a records), so the classes here use delta-V only, for the reference and for every estimate. Class counts of the sealed fold are small for Low (7 records); macro-F1 is averaged over the classes present.
- **Metrics (definitions fixed here).** Macro-F1 over the four classes; balanced accuracy; **under-triage rate** = share of true Severe or Critical records predicted a lower class than their true class; **over-triage rate** = share of true Low or Moderate records predicted a higher class than their true class; **mis-triage** (UA-SCT definition) = share of true Severe or Critical records assigned below Severe; **escalation** (UA-SCT definition) = share of true Low or Moderate records assigned Severe or above (including events that abstain, where a study says so).
- **Sensor settings.** The generic sensor chain of `severity_study.sensor_signal` (4th-order zero-phase low-pass at 260 Hz front end, saturation at the range, digital low-pass at min(0.4 x rate, 260 Hz), linear interpolation onto the sample grid), ranges +-16, +-32, +-64 g, rates 100 and 200 Hz. **Primary rate: 100 Hz** (the setting of the project); 200 Hz cells are reported with the same rules and do not enter the verdicts. Primary range for single-range statements: +-16 g.
- **Seeds.** 42 for single-seeded work; 0 to 4 for repeated runs of models with randomness (CNN, forests of Block 4). Gradient-boosted models are deterministic (single thread, no bagging) and use seed 42.
- **Intervals.** 95% percentile bootstrap, 1,000 resamples. NHTSA studies: whole make-and-model groups are resampled together (`boot._gidx`), and the same drawn groups feed every compared method (paired). VZCrash: test events are resampled, the same events feed every compared method.
- **Selection of anything tunable** (hyper-parameters, thresholds, feature subsets, the best model of a family, interval variants) uses the development and validation folds (NHTSA) or the training and validation splits (VZCrash) only. Each model and each setting is frozen in a commit (`results/tables/p_freeze_<hypothesis>.json`, with the sha256 of the model files); the commit hash of each freeze is recorded in `docs/05_data_code/SEALED_SPLIT.md` and in `results/tables/p_sealed_access.csv`. **The sealed fold is scored once per hypothesis**, after its freeze (`pp_common.sealed_gate` refuses a second scoring unless a dated deviation is given). VZCrash test splits are scored once per model and seed.
- **Holm correction.** One Holm correction over the seven hypotheses H-P1, H-P2, H-P3a, H-P3b, H-P4a, H-P4b and H-P4c. Each hypothesis has one p-value: the largest of the one-sided bootstrap p-values (share of resamples on the wrong side of the criterion margin; floor 0.001) of the conditions that must all hold; for the clause "in at least two of three ranges" the p-value is min(1, 2 x the second-smallest of the three per-range p-values). A hypothesis is SUPPORTED if its stated criterion is met and its Holm-adjusted p-value is below 0.05; MIXED if the criterion is met and the adjusted p-value is not below 0.05; NOT SUPPORTED otherwise. P4d (optional) has no hypothesis. Every result is reported with its interval, favourable or not.
- **Mode (Z1).** A deployed node does not know the crash mode. Every model that uses the mode is reported twice: with the true mode (**oracle**, labelled; not deployable) and with a mode inferred from the pulse (**deployable**). The mode classifier: random forest (300 trees, minimum leaf 2, balanced class weights, seed 42) on features of the clipped sensor window (delta-V components and their angle, peak per axis, rise time, pulse width, clipping descriptors); fitted on development, one per range-and-rate cell; its accuracy on validation and on the sealed fold is reported (balanced accuracy and the confusion matrix). For training a model that takes the inferred mode, the development records get a cross-fitted inferred mode (grouped 5-fold inside development); validation and sealed records get the prediction of the classifier fitted on all of development. "Deployable" = uses no mode or the inferred mode.
- **Origins.** All P1 to P4 numbers are MEASURED_SOFTWARE except: flash and RAM estimates (ANALYTICAL, unless a compiled size is measured: then MEASURED_SOFTWARE on the stated host or target) and the UA-SCT cells of P3b (SIMULATED).
- **Novelty scope notes** for each study are in `docs/06_references/NOVELTY_SCAN.md` (written before the study runs). The words of the project wording rule are not used in generated text.

## 1. P1. Severity triage as a classification problem

**Estimators and models (all trained on development only).**
(a) plain delta-V of the clipped signal, binned. (b) fill + ridge (N14: triangle pulse, clip level 0.7, release fraction 0.1; ridge strength by leave-one-group-out inside development), binned. (c) the X6 anchored estimator (boosting of the log correction, never below plain; the Study A feature set; boosting settings fixed: 100 trees, depth 2, learning rate 0.05, subsample 0.8, seed 42), binned. (d) direct ordinal gradient-boosted classifier (LightGBM; three cumulative binary models for y > Low, y > Moderate, y > Severe; predicted class = number of cumulative probabilities at or above 0.5; no threshold tuning) on clipping descriptors and waveform features: delta-V of the clipped signal, pulse length, clipped duration, number of clipped runs, clipped share, time to the earliest clipped sample, rise rate to the clip, area before the clip, area of the unclipped part, peak of the unclipped part (as a share of the range), slopes into and out of the clip, ratios (clipped duration over pulse length, area before clip over time to clip, peak of the unclipped part over the range, delta-V per millisecond of pulse). **Monotone (non-decreasing) constraints** where physics supports them: delta-V of the clipped signal, clipped duration, clipped share, area of the unclipped part, peak of the unclipped part. Hyper-parameters chosen on validation macro-F1 from leaves {4, 8} x trees {50, 150, 300} (learning rate 0.05, minimum leaf 10; ties go to fewer trees, then fewer leaves). Mode input: none, oracle or inferred (Z1). (e) a small 1D CNN on the clipped waveform (three channels: x, y and the resultant, divided by the range; window 0.1 s before to 0.4 s after the trigger at the cell's rate; conv 3-16 (k5), conv 16-32 (k5, stride 2), conv 32-32 (k3), global max and mean pooling, a dense layer of 32 units, three cumulative-probability outputs; Adam, learning rate 0.001, batch 32, at most 150 epochs, the epoch chosen on validation macro-F1; mode concatenated before the dense layer in the oracle and inferred variants). Seeds 0 to 4; the model is the average of the five seeds' cumulative probabilities; the per-seed macro-F1 spread is reported. (f) the best of (d) and (e) with training-data augmentation: on every development record, 6 augmented copies with time scaling of the pulse (factor log-uniform on [0.8, 1.25]), amplitude scaling (log-uniform on [0.7, 1.4], applied to the physical signal before the sensor model, so clipping follows), additive white noise on the sensor output (standard deviation uniform on [0.005, 0.03] g) and a random resampling phase (uniform within one sample); the reference delta-V and class of an augmented copy are recomputed from the augmented original-rate signal. Augmentation touches development training data only. (f) is built for (d) and for (e); the one used in the hypothesis is the better of the two by validation macro-F1.

**Primary comparison (H-P1).** At each range at 100 Hz, the best deployable direct model (validation macro-F1 chosen among (d), (e), (f) with the inferred mode or with no mode) against the best of (a) to (c) (validation macro-F1 chosen among the three), both frozen, then scored on the sealed fold: paired differences (direct minus baseline) of macro-F1 and of the under-triage rate, grouped bootstrap. Also reported: every model and every cell (6 cells), oracle-mode variants (labelled), over-triage, balanced accuracy, mis-triage, per-mode results, and the +-16 g result alone.
**H-P1.** In at least two of the three ranges, macro-F1 of the best deployable direct model is higher by at least 0.03 with the interval of the difference above zero, AND its under-triage rate is lower by at least 0.03 with the interval of the difference below zero. **Counts against:** in two or more ranges either interval includes zero (or the point difference is under 0.03). The +-16 g result is reported on its own and is not a separate hypothesis.
**EXPLORATORY (not part of H-P1):** grouped 5-fold cross-validation over all 913 records for (a) to (d), to show the size of the differences with more records than the sealed fold.

## 2. P2. Certified severity interval from a physical lower bound

The plain estimate is below the reference in almost all tests, so it is a one-sided bound. Interval = [plain, plain x q]. q is a conformal quantile of the ratio reference / plain on the VALIDATION fold (whole groups stay in the fold; models of the base estimator are not used: the interval is a function of the plain estimate). Target coverage 90%: the upper level is 1 - alpha with alpha = 0.10 minus the share of validation records whose reference is below the plain estimate (floor alpha = 0.02), and q = the ceil((n + 1)(1 - alpha))-th smallest ratio. Variants: **global q (primary)**; q by clipping-severity bin (Mondrian; bins of the clipped duration of the window, a quantity the node computes: none, then the two halves of the clipped records at the development median); q by inferred mode (Z1, deployable); and, EXPLORATORY, a global q with each validation record weighted by 1 / group size. **Existing interval:** the relative-residual split-conformal interval around fill + ridge (S9/N24 in its split form: calibration = validation, interval [f (1 - r), f (1 + r)] with r the 90% conformal quantile of |reference - f| / f; the lower end is clipped at 0.1 x f; the upper-to-lower ratio is (1 + r) / max(1 - r, 0.1)). The grouped CV+ form of N24 is reported as EXPLORATORY.
Metrics on the sealed fold: coverage overall and per true mode (grouped intervals), mean upper-to-lower width ratio, mean width in km/h, share of frontal barrier intervals inside the physical band v <= delta-V <= 2 v (v = closing speed of the test; both ends inside), at +-16, +-32 and +-64 g and 100 Hz (200 Hz reported).
**H-P2 (primary variant: global q; +-16 g, 100 Hz).** The lower end of the 95% grouped interval of the sealed coverage is at least 0.85 overall and in each mode with at least 50 sealed records (by the split this is pole only; frontal barrier, side and other have fewer and are reported descriptively), AND the point estimate of the relative reduction (existing ratio - new ratio) / existing ratio of the mean upper-to-lower width ratio is at least 0.20 with the lower end of its grouped interval above zero. **Counts against:** the coverage lower end is below 0.85 overall or in any mode with at least 50 records, or the width reduction is under 0.20 or its interval includes zero. The result says which condition failed. The p-value of the width clause is the share of resamples with reduction at or below 0.20; that of the coverage clause the share with coverage at or below 0.85 (overall and pole; the larger).

## 3. P3. Knowing when the clipped reading cannot be trusted

**P3a (selective prediction).** Reliability score s(x): a gradient-boosted regression (settings as in (c)) on the clipping descriptors of (d), fitted on development to predict log(reference / plain) (the amount by which the plain estimate under-reads); the score is cross-fitted inside development (grouped 5-fold) for the development rows. Optional addition (chosen on validation by the retained p90 error of the anchored estimator at 70% retention, at +-16 g): the class probabilities of the best deployable direct model of P1 (maximum probability and entropy) as further inputs. An event abstains when s(x) exceeds the 70th percentile of s on the VALIDATION fold (fixed threshold, frozen). Risk-coverage curves (p90 absolute delta-V error and under-triage against the retained share, retention 100% down to 30% in steps of 5 points, by the ranking of s) for plain, fill + ridge, anchored and the best direct model, at +-16 and +-32 g, 100 Hz, on the sealed fold; also the share of true Severe or Critical records that abstain.
**H-P3a.** Primary estimator: the anchored estimator (c) at +-16 g, 100 Hz; retention fixed by the validation threshold (the realised retained share on the sealed fold is reported; a variant that keeps exactly 70% of the sealed records by rank uses no labels and is reported next to it). Under-triage among retained events is at most half the unselected rate (point estimate of the ratio retained / unselected at most 0.5, and the upper end of the 95% grouped interval of the ratio below 1), AND the p90 delta-V error among retained events is at most 20% (point estimate). **Counts against:** either fails, or the interval of the ratio includes 1. The p-value is the larger of: share of resamples with ratio at or above 1, and share with retained p90 error at or above 20%.

**P3b (abstain as an escalation signal).** Setup of T1: the UA-SCT simulator (`sct_sim`, parameters of `s11.tuned.*`), the same scenario cells (steady and burst, the one-factor variants), seeds 3000 + hour with 30 seeds per cell (hours 0 to 29), the sealed-fold class pairs (true class, assigned class) at the range, with the delay and false-alarm pools of `s11_sct.load_pools`. Systems: **A** = the SCT policy with the anchored estimator's point class, where abstaining events (frozen P3a threshold) are assigned Critical (sent to the fast path); **P1e** = the severity-table policy with the same point class, every class boundary divided by a factor f; **P2e** = the SCT policy with the same lowered point class. f is chosen on the VALIDATION fold, on the grid 0.30 to 1.00 in steps of 0.0025, so that the escalation of the lowered table on validation equals the escalation of A on validation (no simulated outcome is used). The escalation of both on the sealed fold is reported with the gap; a comparison at equal escalation by interpolation on the sealed curve is reported as EXPLORATORY.
**H-P3b (+-16 g, 100 Hz).** Pool-level mis-triage of A minus that of P1e on the sealed pairs is at most -0.02 (point), with the 95% grouped paired interval entirely below zero. **Counts against:** the interval includes zero or the reduction is under 2 points (N28 then stays NO_IMPROVEMENT_FOUND, and this is said). The simulated cells (SIMULATED) report mis-triage, escalation, critical reach within 10 s and 30 s, and node airtime, with intervals over seeds; they are descriptive for this hypothesis.

## 4. P4. The VZCrash detector

Data and code: the supplied splits, `detector_extra.frames_full` (training = triggered training windows; validation = all validation events; test = the de-duplicated test events, 24,022 events, PRIMARY); the strict set (22,830 events) is the sensitivity set and the primary set for H-P4b. The 14 features of `config.FEATURES`. Thresholds from validation only (`threshold_for_fpr`: system-level false-alarm rate over all non-crash events). Metrics: AP of triggered test events, system recall at the 1% and 5% false-alarm targets, system recall at the validation-F1 threshold. Seeds 0 to 4, 5-seed mean, paired bootstrap over test events.

**P4a. Memory-accuracy Pareto.** Sweep trees 2 to 10, depth 3 to 9, feature-subset size k in {4, 6, 8, 10, 14} (features ranked by the mean impurity importance of the full 10-tree depth-9 forest over seeds 0 to 4 on the TRAINING split; the top k), float and 16-bit thresholds and leaves (X1 quantiser). Flash (ANALYTICAL) = nodes x bytes per node (9 bytes with float32 thresholds, 7 bytes with 16-bit, the layouts of X1) summed over the trees of the seed-mean; RAM (ANALYTICAL) = 4 bytes per feature + 4 bytes accumulator + 16 bytes of loop state, plus a configuration-independent window buffer of 280 x 3 x 2 bytes, stated separately. If gcc is usable, the C code of selected configurations is compiled and its `.text` size is measured (MEASURED_SOFTWARE, host x86-64, `-Os`, not an ESP32 figure; no microcontroller cross compiler and no emlearn were available at the time of writing, stated in `docs/07_log/DECISIONS.md` if still true). The reference ("current") model: the 10-tree depth-9 forest with all 14 features and float thresholds; its flash estimate is the "current flash estimate". Selection for H-P4a: among configurations whose validation AP (5-seed mean, triggered validation events) is within 0.005 of the reference's, the one with the smallest flash estimate (ties: fewer RAM bytes, then fewer trees); the sweep is scored on the test split only once per model, for the Pareto figure, never for selection.
**H-P4a.** The selected configuration has at most half the current flash estimate and the upper end of the 95% interval of (reference AP - its AP) on the de-duplicated test set is at most 0.01. **Counts against:** no configuration satisfies the validation rule, or the selected one has more than half the current flash estimate or an interval upper end above 0.01. The p-value is the share of resamples with AP loss at or above 0.01.

**P4b. Augmentation with group-aware sampling.** Variants of the 15-tree depth-6 forest of the headline (`rf15`): standard; and augmented: on crash training windows, 2 augmented copies each with a time shift (uniform integer shift of the signal relative to the trigger within +-10 samples, edge repeat), amplitude scaling (log-uniform on [0.8, 1.25] on the physical reading, then clipped at +-16 g) and additive noise (standard deviation uniform on [0.01, 0.05] g on each axis), the 14 features recomputed; and near-identical training windows (identical 280-sample windows, the X3 groups) merged into one training unit (one window kept per group; for augmented copies the unit is the group). Thresholds from the unchanged validation split.
**H-P4b.** Recall at the 1% false-alarm target on the strict test set is at least 0.02 higher than standard training (5-seed mean of the paired difference at least 0.02, interval above zero). **Counts against:** the interval includes zero or the gain is under 2 points. X3 (down-weighting, merging) is the closest earlier result and is cited as such.

**P4c. Restoring the false-alarm guarantee under vehicle shift.** The only vehicle label is the vehicle size (Light, Medium, Heavy, Unknown); there is no vehicle identifier (X4). **Groups = vehicle-size categories.** Model: `rf15`, seeds 0 to 4. Calibration negatives = non-crash validation events (system level: events the trigger discards count as non-alarms). Targets alpha = 0.01 and 0.05. Variants: (V0) the trivial rule: lowest threshold meeting the rate on the pooled calibration set (`empirical_threshold`); (V1) pooled split-conformal (`conformal_threshold`; the existing X4 method); (V2) conformal calibration by group: one conformal threshold per category, used for events of that category; (V3) CV+ with category groups: K models each trained without one training category, calibration scores of the validation negatives of category k from model k when it did not see k, test event alarms if its CV+ conformal p-value is at most alpha; (V4) conformal risk control with group-level calibration: the threshold is the smallest for which the mean over groups of (n_g R_g + 1) / (n_g + 1) is at most alpha, with R_g the false-alarm rate of group g on the calibration set; (V5) the most conservative group-wise calibration quantile (maximum over groups of the group conformal thresholds).
**Evaluation (primary): leave-one-category-out.** For each held-out category c: calibration groups are the other categories (V2 cannot use group c and falls back to pooled V1 for it; V4 and V5 use the other groups only; V3 trains without c as well), the test events are the de-duplicated test events of category c, and the results are pooled over c (event-weighted); 1,000 bootstrap resamples of test events within category, 5-seed mean. Also reported (secondary): the pooled supplied test split with calibration on all validation categories. 
**H-P4c.** Some variant (V1 to V5) has, at both 1% and 5%, an observed false-alarm rate with the 95% upper end at most alpha + 0.01, AND recall at least 0.02 above that of the trivial rule (V0) at the same target. **Counts against:** no variant does; the failure of the guarantee is then reported as a limitation of the dataset's vehicle structure (no vehicle identifier). The p-value: the largest over the two targets of the share of resamples where the false-alarm rate is at or above alpha + 0.01 or the recall gain is at or below 0.02, for the variant with the smallest such value among V1 to V5 (multiplied by 5 for that choice, capped at 1).

**P4d (optional, EXPLORATORY).** An int8 tiny 1D CNN against the forest on AP and estimated flash, run only if time remains; no hypothesis.

## Addenda

### Addendum 1 (2026-11-12, written after the P1, P2 and P3 freezes were committed and before the sealed fold was scored; P4a had been scored and P4b was being scored)

Clarifications of the text above. None changes a hypothesis, metric, threshold or rule; each says how an unspecified detail was resolved.
1. **p-values.** The bootstrap p-value of a condition of the form "interval above zero" uses the margin 0 (share of resamples at or below 0 for a gain, at or above 0 for a reduction of under-triage). Where the criterion also names a point margin (0.03, 0.02, 0.20, 0.01 +alpha), that margin is checked on the point estimate; where the text of a hypothesis gives the margin for the p-value (H-P2 width clause 0.20, H-P3a retained p90 0.20, H-P4a 0.01, H-P4b 0.02, H-P4c alpha + 0.01 and 0.02) that margin is used.
2. **P1.** The ordinal GBM and the CNN are trained on the development records only; the validation fold chooses the hyper-parameters, the CNN epoch, the best baseline and the best deployable direct model per cell; ties go to the earlier name in the order a, b, c, d_none, d_inferred, e_none, e_inferred, fd_none, fd_inferred, fe_none, fe_inferred. The oracle comparison uses the oracle-mode variant with the best validation macro-F1. The ridge of (b) and the anchored estimator of (c) use the feature set of `pp_models.anchor_x` (the Study A set with the pulse length of the severity code instead of that of `v2_clip`). Classes absent from a bootstrap resample are not averaged in macro-F1.
3. **P3a.** The class-probability inputs of the score variant s2 come from the no-mode direct GBM (cross-fitted inside development; the frozen P1 model elsewhere) whatever the best direct model is. The score regressor is fitted on all development records and is not cross-fitted (nothing uses its development scores). "Retained" means score at or below the validation 70th percentile.
4. **P3b.** The anchored point class at +-16 and +-32 g is used for A, P1e and P2e; the lowered table uses the anchored estimate divided by f. +-64 g is not run (no P3a score at +-64 g).
5. **P4b.** `frames_full` returns the de-duplicated test events, so the de-duplicated set is the whole frame and the supplied (24,174-event) set is not scored. The initial run of the evaluation stopped before scoring because of a code error (`te.leaky` does not exist); see `results/tables/p_sealed_access.csv` and `docs/07_log/DECISIONS.md`.
6. **P4c.** In the leave-one-category-out evaluation V2 has no calibration data of the held-out group and falls back to the pooled V1 threshold, so V2 equals V1 there; the pooled supplied-test evaluation (secondary) is where V2 differs. V3 is scored in the leave-one-category-out evaluation only.
7. **P4a.** The selection margin of 0.005 validation AP is part of the rule as written; the sweep scored the test split once for all configurations after the freeze.
