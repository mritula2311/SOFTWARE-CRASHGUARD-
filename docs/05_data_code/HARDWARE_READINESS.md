## 1. What each hardware experiment adds
| ID | Experiment | Software result it would replace or complete | Log files |
|---|---|---|---|

## 4. How to merge real logs
Put the files in `data/hardware/` (read-only for this repository), then run `python merge/ingest_hardware.py` (or `make merge`). A hardware number is written to `results/results.json` with the origin label HARDWARE; nothing is edited or extended.
