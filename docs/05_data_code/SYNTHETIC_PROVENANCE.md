## The earlier generator (blocks C and G)

`results/synthetic/generator_params_all913.json` was fitted to all 913 pooled records, which include the validation and sealed folds. It is a provenance problem for any result that treats the sealed or validation records as independent of the generator. Affected: the stress test H-C3 and the class pairs of the block G simulator grids. Refit: FAM above (the same family generator refit on the development fold only). Block A of this release does not use synthetic pairs at all: its class pairs are the real out-of-fold pairs of the nested cross-validation (`docs/02_preregistration/PREREGISTRATION_V7.md`). The H-C3 stress test is not rerun in this release; its original result is kept and labelled as fitted to all records.
